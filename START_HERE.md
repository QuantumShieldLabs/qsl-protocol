# Start here

Choose a path according to what you want to learn or contribute.

| Audience | Reading path |
|---|---|
| First visit | [README](README.md) -> [public evidence guide](docs/public/INDEX.md) |
| Security reviewer | [claim boundary](docs/public/SUITE2_TRIPLE_RATCHET_CLAIM_BOUNDARY.md) -> [canonical specifications](docs/canonical/) -> [external review package](docs/public/EXTERNAL_REVIEW_PACKAGE.md) |
| Implementer | [canonical specifications](docs/canonical/) -> [conformance inputs](inputs/suite2/) -> [reference implementation](tools/refimpl/) |
| Contributor | [contribution guide](CONTRIBUTING.md) -> affected source, tests and CI workflow |
| Desktop explorer | [qsl-desktop](https://github.com/QuantumShieldLabs/qsl-desktop) and its feature-status table |

QSL is research-stage, not independently audited and not production-ready. Evidence and experiments apply to their named revision and assumptions. See [SECURITY.md](SECURITY.md) before sharing a sensitive finding.

Accepted specifications and recorded decisions govern technical changes. Discuss substantive implementation work with maintainers before opening a PR. Historical plans and experiment reports preserve their original scope; their presence does not authorize a new task or establish current completion.

The [documentation index](docs/INDEX.md) provides deeper navigation. Use [SUPPORT.md](SUPPORT.md) for questions and [CONTRIBUTING.md](CONTRIBUTING.md) for the public contribution process.
