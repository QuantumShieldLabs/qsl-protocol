# Support and discussion

QSL is a research project with no production support commitment.

- **Reproducible bugs:** open an issue in the affected repository with its revision, environment and synthetic reproduction.
- **Design or contribution questions:** use repository Discussions when enabled; otherwise open a focused question issue.
- **Sensitive security findings:** follow [SECURITY.md](SECURITY.md). Do not include details in a public issue.
- **Protocol or evidence orientation:** start with the qsl-protocol README and public evidence guide.

Check the repository's documented capabilities before trying a workflow. Keep real personal data, credentials and private logs out of support requests. No response-time or recovery guarantee is offered.
